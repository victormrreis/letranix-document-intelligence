# LETRANIX — Document Intelligence Platform

Aplicação local de demonstração para importar documentos sintéticos, extrair texto e campos, revisar os resultados e registrar uma integração fictícia com autorização explícita. Interface em inglês; slogan: **Do documento bruto ao dado confiável.**

O código foi implementado separadamente a partir de requisitos funcionais genéricos. Nenhum código, documento, banco ou modelo operacional foi importado. Isso não constitui liberação jurídica de distribuição. A publicação desta prévia de código foi autorizada em 29/10/2026. Nenhuma licença aberta foi concedida; a revisão jurídica e as limitações de distribuição continuam documentadas.

Siga o [guia de instalação](GETTING_STARTED.md), os comandos do [README principal](../README.md) e o [roteiro de três minutos](DEMO.md). Os resultados executados estão em [VALIDATION.md](VALIDATION.md). A interface funciona no navegador local; a janela Tauri exige o serviço Python já iniciado. Instalador autônomo e assinatura não estão entregues.

O OCR de imagens é real e opcional. PDFs digitalizados precisam ser exportados como imagens; PDFs com texto nativo são suportados diretamente. Manuscritos são experimentais. Correções geram histórico, não treinamento de IA. A aplicação não deve receber dados reais durante esta avaliação.
